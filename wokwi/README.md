# Berkas Wokwi

Folder ini berisi berkas pendukung simulasi di [Wokwi](https://wokwi.com).

| Berkas | Isi |
|---|---|
| `libraries.txt` | Daftar library yang dipakai proyek |
| `diagram.json` | Rangkaian (komponen dan kabel) |

## Menambahkan `diagram.json`

Berkas `diagram.json` :

1. Buka proyek Anda di Wokwi.
2. Klik tab **libraries.txt**.
3. tempel isi `libraries.txt`.

## Menambahkan `diagram.json`

Berkas `diagram.json` :

1. Buka proyek Anda di Wokwi.
2. Klik tab **diagram.json**.
3. tempel isi `diagram.json`.
