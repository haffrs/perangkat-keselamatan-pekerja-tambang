# Berkas Wokwi

Folder ini berisi berkas pendukung simulasi di [Wokwi](https://wokwi.com).

| Berkas | Isi |
|---|---|
| `libraries.txt` | Daftar library yang dipakai proyek |
| `diagram.json` | Rangkaian (komponen dan kabel) |

## Menambahkan `diagram.json`

Berkas `diagram.json` harus disalin dari proyek Wokwi Anda sendiri agar sama persis dengan rangkaian yang diuji:

1. Buka proyek Anda di Wokwi.
2. Klik tab **diagram.json**.
3. Pilih semua isinya (Ctrl+A), salin (Ctrl+C).
4. Simpan sebagai `wokwi/diagram.json` di repositori ini.

Untuk memakai rangkaian ini di proyek Wokwi baru, lakukan langkah sebaliknya: tempel isi `diagram.json` ke tab `diagram.json`.
